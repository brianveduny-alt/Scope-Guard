# Scope Guard for Jira Cloud

Scope Guard helps agencies, consultancies, and delivery teams track contract hours, monitor retainer budgets, and prevent scope creep directly inside Jira Cloud.

## Installation
1. Install **Scope Guard** from the Atlassian Marketplace into your Jira Cloud site.
2. Open any Jira project and navigate to **Scope Guard** in the project sidebar.

## Getting Started
1. **Set Your Contract Budget:** Enter the total contracted hours or monthly retainer limit for your project.
2. **Log Work as Usual:** Scope Guard automatically tracks logged time across project issues.
3. **Monitor Thresholds:** View real-time remaining hours, billable vs. non-billable breakdowns, and budget alerts before scope creep impacts your margins.
